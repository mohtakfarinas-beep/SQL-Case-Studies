# SQL-Case-Studies
My solutions to two case studies from Danny Ma's [8 Week SQL Challenge](https://8weeksqlchallenge.com), written in MySQL.

## Projects

| Project | Challenge | Skills |
|---|---|---|
| [Danny's Diner](dannys-diner/) | [Case Study #1](https://8weeksqlchallenge.com/case-study-1/) | Joins, CTEs, window functions, `CASE WHEN` |
| [Pizza Runner](pizza-runner/) | [Case Study #2](https://8weeksqlchallenge.com/case-study-2/) | Data cleaning, date functions, conditional aggregation |

## How to run

Each folder has a `solutions.sql` file with the table creation at the top. Use MySQL 8 or later, run the creation block once, then the queries.
